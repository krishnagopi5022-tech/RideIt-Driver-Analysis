# 🚖 RideIT Driver Engagement Analysis | Power BI Project

## 📖 Project Overview

This project was developed as a **Power BI case study** to analyze driver engagement and operational performance for RideIT, a mobility platform offering ride-hailing and shared transportation services.

The dashboard helps business stakeholders monitor driver activity, identify engagement patterns, analyze ride performance, and support data-driven decision-making.

---

## 🎯 Business Objective

The primary objective of this project is to:

- Measure driver engagement using operational KPIs.
- Analyze booking and ride completion trends.
- Identify factors affecting driver performance.
- Monitor cancellation patterns.
- Provide actionable business recommendations to improve driver engagement.

---

## 📂 Dataset

The project uses two datasets:

### Rideit_drivers
Contains driver profile information:
- Driver ID
- Registration Date
- Driver Rating
- Gold Level Count
- Marketing Preference
- Country
- Service Type

### Rideit_drivers_activity
Contains daily driver activity:
- Driver ID
- Active Date
- Ride Offers
- Bookings
- Completed Rides
- Driver Cancellations
- Passenger Cancellations

## 📌 Key Business Insights

- Ride completion remained above 80%, indicating good operational performance.
- Passenger cancellations contributed more than driver cancellations.
- Higher-rated drivers generally completed more rides.
- Drivers with higher Gold Level counts showed stronger engagement.
- Booking trends and cancellation rates can be monitored to identify operational improvements.

---

## 💡 Business Recommendations

- Introduce incentive programs for highly engaged drivers.
- Reduce cancellation rates through targeted driver education.
- Improve onboarding for new drivers to increase long-term engagement.
- Use marketing campaigns to encourage driver participation.
- Continuously monitor engagement KPIs to evaluate business performance.
